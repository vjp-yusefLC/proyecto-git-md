# Documentación del despliegue LAMP con monitorización

Este repositorio contiene la documentación completa para el despliegue de una infraestructura LAMP (Linux, Apache, MySQL/MariaDB y PHP) con monitorización, copias de seguridad y plan de recuperación.

## Autores (pareja)
- Cuenta 1: **yuseflc (Documentalista de plataforma)**
- Cuenta 2: **vjp-yuseflc (Documentalista de operaciones)**

## Estructura de la documentación
Toda la documentación se encuentra en la carpeta [`/docs`](./docs).

Incluye:
- Análisis y diseño de la infraestructura
- Instalación del servidor web, base de datos, SSH y firewall
- Monitorización y backups
- Guía de operación y recuperación ante desastres
